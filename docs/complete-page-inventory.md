## Architecture that constrains the design

React 19 and Vite use one marketplace root in src/main.jsx. shared/app-routes.js parses URLs, allowlists return targets and drives history and popstate. The shell also renders screens from local page, modal and tab state. Admin is a separate lazy React root with its own path dispatch and session. Preserve both roots. Use the existing Logo component and public/brand/loop.svg. The orange linked loops in the shipped artwork differ from the purple infinity symbol on the boards. Apply purple to the interface and retain the official file.

The client refreshes /api/state, handles session loss, notifications and mutation results, and submits request mutations with clientMutationId. Vercel routes /api/assistant to its own function, /api/recovery/* to campusloop-recovery, and other /api/* traffic to campusloop-api on Supabase. Review worker/api.js, server/index.js, server/admin.js and the Supabase wrappers together. Local Express and hosted Worker implementations have distinct storage and auth adapters. A local test cannot verify production Google origins, private storage, phone delivery or Gemini credentials. Keep server-side ownership, cookie, role, origin and admin checks, request revision checks and direct payments intact.

## Cross-screen state checklist

* On each data surface cover initial load, loaded rows, true empty state, filter with zero matches, retryable network error, session loss and unauthorized access. Preserve the difference between failed fetch and an empty result.
* Exercise a valid and invalid submission, saving state, failed response, retry without duplicates and successful return to context. Browser back, refresh and safe next must preserve the intended destination and must clear private content after logout.
* For request status filters derive labels from stored request/offer/order/booking state. Open, Booked, Completed, Cancelled, Resent and food seller decisions represent different lifecycles. An offer status cannot be substituted for the whole request.
* Verify notification read/unread and archive isolation with two accounts. Check photos, arbitrary gallery aspect ratios, playback, dismissed dialogs and keyboard focus. Test denied geolocation, maps unavailable, unsupported install and push, declined permission, expired sessions and upstream assistant errors.
* Verify auth role setup, switch-to-required-role, linked accounts, login prompt over draft and account recovery separately. All administrative navigation and mutations require an admin session.
* Baseline test scripts are in package.json. Build before hosted/PWA and HTTP entry tests because they consume generated worker/assets.js and dist. The Node entry-render suite renders components to markup; it does not validate mobile layout.
